## 놀면서 배우고, 만들면서 법니다

**놀면서 배웁니다.** 좋은 학습 게임을 하는 아이는 누가 시키지 않아도 실력을 연습하고, 어른은 아이가 무엇을 연습했는지 확인할 수 있습니다.

**만들면서 법니다.** 게임을 만드는 사람은 두 번 법니다. 먼저 이해를 얻습니다. 수업을 게임으로 바꾸려면 게임에게 설명할 수 있을 만큼 내용을 잘 알아야 하기 때문입니다. 그다음은 수익입니다. 스토어에 올린 게임은 판매할 수도 있고, 아이들이 플레이한 시간만큼 수익을 받을 수도 있습니다.

이 스킬들은 게임을 한 번도 만들어 본 적 없는 사람도 두 가지를 모두 할 수 있게 해 줍니다. 숙제를 설명하면 AI가 함께 게임을 만들고, 스토어 요건에 맞는지 점검하고, 게시까지 도와줍니다.

## 학부모를 위해: 안전한 공간, 그리고 성장을 지켜보는 방법

**스토어 규칙으로 지키는 안전.** 모든 게임은 등록 전에 같은 요건으로 테스트를 거칩니다. 먼저 제작자가, 그다음 MEXTY 심사자가 확인합니다. EdVerse의 게임은 다음과 같습니다.

- 광고, 채팅, 게임 밖으로 나가는 링크, 구매 버튼, 가입을 요구하는 화면이 없습니다.
- 아이의 이름, 이메일, 사진, 위치를 묻지 않으며 추적기도 없습니다.
- 폭력적이거나 무섭거나 조롱하는 내용이 없고, 계속 플레이하거나 결제하도록 아이를 압박하는 요소도 없습니다.
- 틀린 답도 다정하게 다루며, 소리는 끌 수 있습니다.
- 한 번만 누르면 되는 신고 버튼이 있고, MEXTY 직원이 직접 답합니다.

**아이가 배우는 내용을 따라갑니다.** EdVerse에서는 어른이 아이를 각각 학습자로 추가하면 아이별 대시보드를 받습니다.

| 볼 수 있는 항목 | 알 수 있는 것 | |
|---|---|---|
| 플레이 시간, 플레이한 게임 수, 활동한 날 수 | 얼마나 많이, 얼마나 꾸준히 하는지 | 무료 |
| 플레이하는 시간대 | 아침, 방과 후, 저녁 중 언제인지 | 무료 |
| 익힌 능력 | 꾸준히 정답을 맞히는 내용 | 학습자 시트 |
| 연습이 필요한 능력 | 정답률이 60% 미만인 능력 | 학습자 시트 |
| 과목과 게임별 진행 상황 | 시간을 어디에 쓰는지 | 학습자 시트 |

학습자 시트는 아이 한 명당 월 €5부터이며, 모든 ★ Included(시트에 포함) 게임도 함께 이용할 수 있습니다.

## 크리에이터를 위해: 만들고, 등록하고, 듣고, 법니다

AI 구독 하나만 있으면 한 사람이 전 과정을 돌릴 수 있습니다. 제작은 무료입니다. MCP 도구는 MEXTY 크레딧을 쓰지 않습니다.

1. **만듭니다**: 잘 아는 수업 내용으로 게임을 만듭니다([`homework-to-game`](skills/homework-to-game/SKILL.md)).
2. **심사를 통과합니다**: 11가지 EdVerse 게임 요건을 충족합니다([`edverse-game-qa`](skills/edverse-game-qa/SKILL.md)).
3. **등록합니다**: 무료, 정가, 원하는 만큼 내기, 또는 학습자 시트가 있는 가정과 학교를 위한 ★ Included 중에서 고릅니다([`edverse-publish-and-earn`](skills/edverse-publish-and-earn/SKILL.md)).
4. **듣습니다**: 플레이어가 게임의 제안함으로 아이디어를 보냅니다. 수락한 아이디어는 게임의 공개 로드맵이 됩니다.
5. **모읍니다**: Mextribe에 게시하고, 팔로워가 더 많은 것을 원하면 유료 플랜을 추가합니다([`mextribe-community`](skills/mextribe-community/SKILL.md)).
6. **보여 줍니다**: 새로운 것을 출시할 때마다 릴스, 스토리, 캐러셀을 만듭니다([`instagram-showcase`](skills/instagram-showcase/SKILL.md)).

## 컴플라이언스, 그리고 스스로 최신 상태를 유지하는 교육

컴플라이언스 교육은 조용히 실패합니다. 규정은 바뀌는데 코스는 그대로이기 때문입니다. MEXTY에서는 코스마다 출처, 버전, 담당자가 있고, AI 에이전트가 출처를 대신 지켜봅니다.

| 시점 | 일어나는 일 |
|---|---|
| 규정, 법률, 제품 소개서가 바뀔 때 | 에이전트가 새 버전을 읽고, 이를 인용하는 코스를 찾아 변경 초안을 작성합니다. 그 이상은 하지 않습니다 |
| 학습자에게 공개되기 전 | 코스 담당자가 초안을 검토하고, 누가 수강 중이고 누가 인증받았는지 확인한 뒤, 바로 게시하거나 규정 시행일에 맞춰 예약합니다 |
| 중요한 변경이 있은 뒤 | 이전 버전의 수료증을 가진 사람을 확인하고, 바뀐 부분만 다시 배정합니다 |
| 매주, 정해진 일정에 | 리포트: 무엇이 바뀌었는지, 어떤 초안이 대기 중인지, 누구의 수료증이 곧 만료되는지 |
| 새 코스가 게시될 때 | 에이전트가 조직 밖에서 판매할 수 있도록 랜딩 페이지와 제안 초안을 작성할 수 있습니다 |

개인정보 보호, 보안, 안전보건, 행동 강령, AI 리터러시, 제품 교육에 활용할 수 있습니다. 사람의 동의 없이는 아무것도 게시되거나 인증되거나 판매되지 않습니다. [`keep-training-current`](skills/keep-training-current/SKILL.md)를 참고하세요.

| **검토하기** | 검토자를 지정하고, 콘텐츠에 댓글을 달고, 변경 사항과 영향받는 사람을 확인한 뒤 승인하거나 돌려보냅니다 | 무엇이 바뀌었는지 오브젝트별, 파일별로 확인합니다. 소유자나 관리자가 병합합니다 |
| **출시하기** | 지금 게시하거나 예약합니다 | 게임에 병합합니다. 심사가 끝나면 스토어에서 새 버전이 플레이됩니다 |
| **되돌리기** | 버전 기록: 비교하고, 어떤 버전이든 초안으로 복원합니다 | 초안은 닫을 수 있고, 충돌은 나란히 놓고 선택합니다 |
| **크레딧** | 공동 저자의 이름이 표시됩니다 | 병합된 작업의 저자는 크레딧에 오르며, 게임이 학습자 풀에서 얻는 수익을 나눠 받습니다 |

한 반이 이 방식으로 게임 하나를 만들 수 있습니다. 교사가 소유자가 되고, 모둠마다 자기 초안에서 작업하며, 병합하기 전에 반 전체가 하나씩 검토합니다. [`build-together`](skills/build-together/SKILL.md)를 참고하세요.

## 무료인 것과 플랜이 필요한 것

| **수익을 얻는 방법** | 게임을 정가 또는 원하는 만큼 내기 방식으로 판매하거나, 플레이 시간에 따라 학습자 풀에서 수익을 받거나(★ Included), 공동 작업에 열려 있는 게임을 개선하고 초안이 병합되면 풀 수익을 나눠 받습니다 | 유료 멤버십 플랜과 단품 판매 | — |

MCP 도구는 MEXTY 크레딧을 쓰지 않습니다. 생각하는 일은 사용자의 AI 구독이 맡습니다. 미디어 생성(이미지, 음성, 3D 모델, 받아쓰기)만 크레딧을 쓰며, [`free-creative-toolkit`](skills/free-creative-toolkit/SKILL.md)이 각각을 무료로 하는 방법을 알려 줍니다.

## 다른 저자들의 스킬도 포함

게임 제작은 그 자체로 하나의 전문 기술이므로, 이 저장소에는 다른 분들이 작성한 스킬도 수정 없이 각자의 라이선스 그대로 담았습니다. 출처와 라이선스는 [`THIRD_PARTY.md`](THIRD_PARTY.md)에 있습니다.

| 폴더 | 내용 | 제공 |
|---|---|---|
| [`third-party/gamedev`](third-party/gamedev) | 스킬 18개: 게임 필, 레벨 디자인, 게임 UI, 오디오, 카메라, 입력, 저장, 성능, 에셋 파이프라인, 빠른 프로토타이핑, three.js 설정, glTF와 라이팅, 그리고 퍼즐, 플랫포머, 슈팅, 카드, 롤플레잉 게임용 플레이북 | [awesome-gamedev-agent-skills](https://github.com/gamedev-skills/awesome-gamedev-agent-skills), Apache 2.0 |

함께 쓰면 좋은 스킬(각자의 출처에서 설치합니다): 모션 그래픽에는 [bang-motion](https://github.com/bangtutorial/bang-motion), 포스터와 캐러셀에는 [canvas-design](https://github.com/anthropics/skills/tree/main/skills/canvas-design), 그리고 [Lemo-Opuscar](https://github.com/lemomo-ai/lemo-opuscar) 필름 스타일.

  수업 내용)  템플릿으로           테스트 플레이는       제안함,                       캐러셀

## 설치

**1. MCP 서버를 연결합니다.** [mexty.ai/connect](https://mexty.ai/connect)에서 연결합니다(Claude, ChatGPT, Cursor, VS Code, Gemini CLI, Codex 등). Claude Code에서는 다음과 같습니다.

```bash
claude mcp add --transport http edverse  https://mcp.mexty.ai/mcp/edverse
claude mcp add --transport http mextribe https://mcp.mexty.ai/mcp/mextribe
claude mcp add --transport http mexty    https://mcp.mexty.ai/mcp/mexty
```

**2. 스킬을 추가합니다.**

Claude Code에 플러그인으로 추가합니다.

```
/plugin marketplace add mext-ai/elearning-agent-skills
/plugin install elearning-agent-skills@mexty
```

또는 원하는 폴더를 복사합니다.

```bash
git clone https://github.com/mext-ai/elearning-agent-skills
cp -r elearning-agent-skills/skills/* ~/.claude/skills/
cp -r elearning-agent-skills/third-party/gamedev/* ~/.claude/skills/          # 선택 사항
cp -r elearning-agent-skills/third-party/webgpu-threejs-tsl ~/.claude/skills/ # 선택 사항
```

Claude.ai: 스킬 폴더를 zip으로 압축해 Settings → Capabilities → Skills(설정 → 기능 → 스킬)에서 업로드합니다. 다른 에이전트: 스킬 하나는 Markdown 파일 하나입니다. 필요한 `SKILL.md`를 에이전트가 읽도록 지정하면 됩니다.

**3. 원하는 것을 말합니다.**

> 우리 딸의 분수 학습지예요. 태블릿으로 할 수 있는 게임으로 만들어 주세요.

> 우리 아들이 이번 달에 EdVerse에서 뭘 배웠고, 우리는 뭘 연습하면 좋을까요?

> 제 게임이 EdVerse 심사를 받을 준비가 됐나요?

> 공개 중인 제 게임에 들어온 제안을 읽고, 이번 주에 뭘 만들면 좋을지 알려 주세요.

> 매주 월요일마다 분수 레벨이 필요한 공동 작업 게임을 찾아서, 초안에 만들고 소유자에게 검토를 요청해 주세요.

> 우리 회사의 개인정보 보호 정책을 퀴즈가 있는 10분짜리 온보딩 코스로 만들어서 신규 입사자에게 배정해 주세요.

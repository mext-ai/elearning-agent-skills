## 玩中学，创中赚

**玩中学。** 孩子玩一款好的学习游戏时，不用别人催就在练习技能，而大人也能看到他们练了什么。

**创中赚。** 做游戏的人有两重收获。第一重是理解：不把一节课吃透到能讲给游戏听，就没法把它变成游戏。第二重是收入：商店里的游戏可以出售，也可以按孩子们游玩的分钟数获得报酬。

有了这些技能，从没做过游戏的人也能两样兼得：描述一下作业，你的 AI 就会和你一起把游戏做出来，对照商店要求逐项检查，并帮你发布。

## 面向家长：一个安全的地方，一种了解进展的方式

**商店规则保障安全。** 每款游戏上架前都要按同一套要求接受测试，先由作者自测，再由 MEXTY 审核员复测。EdVerse 上的游戏：

- 没有广告，没有聊天，没有跳出游戏的链接，没有购买按钮，也不强制注册；
- 不索取孩子的姓名、邮箱、照片或位置，也没有任何追踪器；
- 没有暴力、吓人或嘲弄的内容，也不会诱导孩子不停地玩或付费；
- 答错时温和对待，声音可以关闭；
- 提供一键举报按钮，由 MEXTY 工作人员处理。

**了解他们学了什么。** 在 EdVerse 中，大人把每个孩子添加为学习者，就能获得对应的仪表盘：

| 你能看到 | 它告诉你什么 | |
|---|---|---|
| 游玩时长、玩过的游戏数、活跃天数 | 玩了多少，是否规律 | 免费 |
| 什么时候玩 | 早上、放学后还是晚上 | 免费 |
| 已掌握的技能 | 哪些内容能稳定答对 | 学习者席位 |
| 需要练习的技能 | 正确率低于 60% 的技能 | 学习者席位 |
| 学科以及每款游戏中的进度 | 时间都花在了哪里 | 学习者席位 |

学习者席位每个孩子每月 €5 起，同时解锁所有 ★ Included（席位内含）游戏。

## 面向创作者：制作、上架、倾听、赚钱

一个人加一份 AI 订阅，就能跑通整个流程。制作是免费的：MCP 工具不消耗 MEXTY 点数。

1. **制作**：用你熟悉的一节课做一款游戏（[`homework-to-game`](skills/homework-to-game/SKILL.md)）。
2. **通过审核**：达到 11 项 EdVerse 游戏要求（[`edverse-game-qa`](skills/edverse-game-qa/SKILL.md)）。
3. **上架**：免费、固定价格、随心付，或面向拥有学习者席位的家庭和学校的 ★ Included（[`edverse-publish-and-earn`](skills/edverse-publish-and-earn/SKILL.md)）。
4. **倾听**：玩家把想法投进游戏的建议箱，你采纳的建议会成为游戏的公开路线图。
5. **聚集**：把游戏发布到 Mextribe，粉丝想要更多内容时再添加付费方案（[`mextribe-community`](skills/mextribe-community/SKILL.md)）。
6. **展示**：每次有新内容上线，就做一条 Reel、一条快拍和一组轮播图（[`instagram-showcase`](skills/instagram-showcase/SKILL.md)）。

每笔游戏销售扣除刷卡手续费后，你保留 80%；Mextribe 会员收入扣除刷卡手续费后，你同样保留 80%。

## 合规，以及能自我更新的培训

合规培训的失效往往悄无声息：制度变了，课程却没变。在这里，每门课程都有来源、版本和负责人，AI 智能体可以替你盯着来源。

| 何时 | 会发生什么 |
|---|---|
| 制度、法规或产品资料发生变更 | 智能体读取新版本，找出引用它的课程并起草修改，仅此而已 |
| 在学习者看到任何内容之前 | 课程负责人审核草稿，查看哪些人已报名、已获认证，然后发布，或安排在制度生效当天发布 |
| 发生实质性变更之后 | 你能看到谁持有旧版本的证书，并只重新分配有变动的部分 |
| 每周定时 | 一份报告：有哪些变化，哪些草稿在等待处理，谁的证书即将失效 |
| 新课程发布时 | 智能体可以起草落地页和销售方案，把课程卖到机构之外 |

适用于数据保护、信息安全、健康与安全、行为准则、AI 素养和产品培训。没有人的同意，任何内容都不会被发布、认证或上架销售。详见 [`keep-training-current`](skills/keep-training-current/SKILL.md)。

## 一起创作

无论课程还是游戏，都不是一个人的活儿，所以两款产品都为协作而生。学习者和玩家看到的永远只是已发布或已合并的内容。

| | 在 MEXTY 工作区 | 在 EdVerse |
|---|---|---|
| **并肩工作** | 课程、活动、测评或学习路径的共同作者 | 多人和他们的 AI 助手在同一个实时 3D 编辑器、同一份代码里工作。修改自动合并，不锁定任何内容 |
| **放心尝试** | 草稿：与线上版本并存的、大家正在尝试的修改 | 游戏世界和代码的草稿。通过分享链接加入的人都在草稿中工作 |
| **审核** | 指定审核人，对内容发表评论，查看改动及其影响到的人，批准或退回 | 逐个对象、逐个文件查看改动；由所有者或维护者合并 |
| **发布** | 立即发布或定时发布 | 合并进游戏；审核通过后，商店提供新版本 |
| **回退** | 版本历史：对比，并把任一版本恢复为草稿 | 草稿可以关闭；冲突可以并排对比后取舍 |
| **署名** | 共同作者都会署名 | 已合并内容的作者会获得署名，并分享游戏从学习者资金池获得的收入 |

一个班级可以这样合作完成一款游戏：老师是所有者，每个小组在自己的草稿里工作，合并之前全班逐一审核。详见 [`build-together`](skills/build-together/SKILL.md)。

## 安装

**1. 连接 MCP 服务器**：前往 [mexty.ai/connect](https://mexty.ai/connect)（支持 Claude、ChatGPT、Cursor、VS Code、Gemini CLI、Codex 等）。在 Claude Code 中：

```bash
claude mcp add --transport http edverse  https://mcp.mexty.ai/mcp/edverse
claude mcp add --transport http mextribe https://mcp.mexty.ai/mcp/mextribe
claude mcp add --transport http mexty    https://mcp.mexty.ai/mcp/mexty
```

**2. 添加技能。**

Claude Code，以插件形式安装：

```
/plugin marketplace add mext-ai/elearning-agent-skills
/plugin install elearning-agent-skills@mexty
```

或者复制你需要的文件夹：

```bash
git clone https://github.com/mext-ai/elearning-agent-skills
cp -r elearning-agent-skills/skills/* ~/.claude/skills/
cp -r elearning-agent-skills/third-party/gamedev/* ~/.claude/skills/          # 可选
cp -r elearning-agent-skills/third-party/webgpu-threejs-tsl ~/.claude/skills/ # 可选
```

Claude.ai：把技能文件夹打包成 zip，在 Settings → Capabilities → Skills（设置 → 功能 → 技能）中上传。其他智能体：每个技能就是一个 Markdown 文件，让你的智能体读取所需的 `SKILL.md` 即可。

**3. 说出你想要什么。**

> 这是我女儿的分数练习题。把它变成一款她能在平板上玩的游戏。

> 我儿子这个月在 EdVerse 上学了什么？我们接下来该练什么？

> 我的游戏可以提交 EdVerse 审核了吗？

> 看看我已上线游戏收到的建议，告诉我这周该做什么。

> 每周一，找一款需要分数关卡的协作游戏，在草稿里把关卡做出来，并请所有者审核。

> 把我们的数据隐私政策做成一门 10 分钟的入职课程，带一个小测验，并分配给新员工。
